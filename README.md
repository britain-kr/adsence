# 애드센스팜 새싹반 VVIP Q&A 분석 페이지

이 프로젝트는 카카오톡 오픈채팅방('애드센스팜 새싹반 VVIP')에서 오고 간 4,401건의 메시지를 분석하여 구축한 **자주 묻는 질문(Q&A) 가이드라인 웹페이지(`adsense_qa.html`)**입니다.

강의 내용이 다루고 있는 주제임에도 반복적으로 올라오는 질문들을 방지하고, 수강생들이 겪는 문제 상황(오류, 설정, 애드센스 승인 등)에 대한 해결책을 스스로, 직관적으로 찾아볼 수 있게 돕기 위해 제작되었습니다.

## 📌 주요 기능 및 구성 요소

1. **데이터 요약 및 통계**
   - **분석 기간:** 2026.03.04 ~ 03.19 (16일간)
   - 4천여 건의 메시지 중 실질적인 질문(967건)을 14개의 세부 카테고리로 분류하여 전체 요약 정보를 제공합니다.

2. **질문 유형 시각화 차트**
   - **원형 차트(Pie Chart):** 어떤 주제의 질문 비율이 가장 높은지 색상별로 직관적으로 보여줍니다.
   - **막대 차트(Bar Chart):** 1위(애드센스 승인 신청)부터 순서대로 질문 발생 비율을 랭킹화하여 나열합니다.

3. **카테고리별 맞춤형 Q&A 검색**
   - 블로그스팟 설정 오류, 워드프레스, SEO 등 특정 주제 탭(Tab)을 클릭해, 해당 주제와 관련된 핵심 질문과 '명확한 정답(가이드)'만 필터링하여 읽을 수 있습니다. 아코디언 메뉴로 깔끔하게 구성되었습니다.

4. **질문 전 체크리스트 (Tips)**
   - 수강생들이 질문을 올리기 전 필수적으로 확인해야 할 5가지 규칙(강의 순서 준수, 스크린샷 첨부, 사이트 내 돋보기 검색 활용 등)을 가독성 높은 카드 형태로 강조합니다.

## 🛠 기술 스택 (Tech Stack)
- 순수 **HTML / CSS / Vanilla JavaScript**로만 제작되었습니다.
- 무거운 외부 라이브러리(Chart.js 등)를 사용하지 않고 CSS `conic-gradient` 등을 활용하여 자체적으로 차트 애니메이션과 인터랙션을 경량화하여 구현했습니다.
- 최신 웹 트렌드에 맞춘 고급스러운 다크 테마(어두운 배경 + 네온 포인트 컬러)가 적용되어 있습니다.
